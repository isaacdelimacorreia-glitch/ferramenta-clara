StoryVista — Visualizador privado de mídia
Ferramenta independente para abrir mídia local ou URL HTTPS direta. Não é um serviço que busca stories Instagram/Facebook por usuário. Não há como garantir anonimato em plataformas de terceiros.
Hospedado no Render via GitHub, branch storyvista, sem backend e sem requisição de dados do usuário ao servidor. Imagens e vídeos selecionados como arquivos locais são processados exclusivamente no navegador.
Nenhum anúncio conectado nesta versão; aprovação do Google AdSense, políticas publicitárias e privacidade devem ser verificadas antes de adicionar códigos de publicidade.
